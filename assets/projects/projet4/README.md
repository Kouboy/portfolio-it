# Projet 4 — Médias à sélectionner et vérifier

Cette fiche présente un exercice **OpenClassrooms**, situé dans un cybercafé fictif (byteCAFÉ). Le dépôt est public ; ne pas déposer les livrables bruts sans contrôle de leur contenu.

## Visuels candidats (non publiés à ce stade)

1. **Devis final**, fichier `P4-M1_Devis.pdf` (Mission 1) : recadrer un extrait pertinent, vérifier que les champs administratifs de simulation sont clairement identifiés comme fictifs et ne pas exposer de données personnelles inutiles.
2. **Image FOG**, fichier `P4-M2_L02_Image-FOG.png` (Mission 2) : conserver le nom de l'image, sa taille et son horodatage pour assurer la valeur probante.
3. **Déploiement Partclone**, capture incluse dans la procédure Mission 3 : récupérer uniquement le visuel utile si son extraction est possible ; ne pas affirmer disposer du PNG original.
4. **Active Directory**, fichier `P4-M3_L2_Computers_AD_2026-10-21.png` (Mission 3) : vérifier les trois objets attendus. Éviter d'exposer des comptes, noms d'utilisateurs ou paramètres sensibles supplémentaires.
5. **Schéma pédagogique** du flux masterisation → capture → PXE/Deploy → validation : à créer à partir des étapes documentées, et à étiqueter comme schéma explicatif, non comme capture.

## Contrôles avant publication

- Vérifier identité, adresses, domaines, MAC, codes ou secrets éventuellement visibles ; masquer toute donnée réelle non nécessaire.
- Préserver un recadrage honnête : pas de capture « reconstituée » présentée comme authentique.
- Ajouter un texte alternatif en français et une légende distinguant **preuve**, **schéma explicatif** et **illustration**.
- Conserver la nuance : jonction AD automatique non obtenue sur le second poste ; état du canal sécurisé et synchronisation NTP non entièrement résolus dans le guide client.
- Vérifier la qualité sur écran mobile et les dimensions finales des médias avant intégration.

Sources canoniques de travail : dossier `Projet 4 / Livrables` et soutenance finale sur le Drive personnel. Les fichiers sources restent sur Drive ; les visuels publics seront des dérivés vérifiés.

# Portfolio Signal — Lexique trilingue JP / EN / FR

## Principe général

- **FR = contenu** : explications, raisonnement, contexte, retour d’expérience.
- **EN = interface** : navigation, états, catégories, noms de composants.
- **JP = ponctuation sémantique** : kanji courts servant de repères visuels et conceptuels.

Les trois couches se combinent lorsque leur présence améliore la hiérarchie et la lecture.

## Lexique de référence

| JP | EN | FR | Usage |
|---|---|---|---|
| 修復 | REPAIR / RESTORE | Réparation / remise en état | Réemploi, panne matérielle, restauration |
| 記録 | FIELD LOG / RECORD | Journal / trace | Démarche, notes, chronologie |
| 試験 | TEST | Test / essai | Validation technique |
| 接続 | CONNECTION | Connexion | Réseau, liaisons, topologie |
| 制御 | CONTROL | Contrôle | Administration, accès, permissions |
| 構築 | BUILD / DEPLOY | Construction / déploiement | Mise en place d’un système |
| 診断 | DIAGNOSIS | Diagnostic | Recherche de panne |
| 証拠 | EVIDENCE | Preuve | Captures, mesures, résultats |
| 結果 | OUTCOME | Résultat | État final / validation |
| 観測 | OBSERVATION | Observation | Supervision, vérification |
| 保守 | MAINTENANCE | Maintenance | Entretien, suivi |
| 再利用 | REUSE | Réemploi | Réaffectation d’un matériel |

## Règles

1. Le texte principal reste en français.
2. Les labels d’interface restent en anglais.
3. Les kanji sont courts, stables et cohérents.
4. Un kanji doit avoir une fonction sémantique réelle.
5. Le japonais conserve une fonction sémantique identifiable.
6. La triple présence FR / EN / JP est réservée aux zones où elle renforce la structure.
7. Même fonction = même terme japonais.

Lab Active Directory

Un laboratoire VirtualBox isolé pour manipuler Windows Server 2025, Active Directory, DNS, DHCP et PowerShell dans un environnement reproductible.

01
CONTEXT背景Contexte
PROJECT THEME

Context

Le laboratoire sert de terrain d’apprentissage pour les services Windows d’entreprise tout en restant indépendant du réseau domestique. Les machines virtuelles peuvent être reconfigurées ou restaurées sans impact extérieur.

02
OBJECTIVE目的Objectif
scope / formal

Objective

Disposer d’un réseau suffisamment réaliste pour joindre un poste au domaine, travailler sur les dépendances AD DS / DNS / DHCP et automatiser quelques tâches administratives.

03
FIELD LOG記録Démarche

Protocol

LOG 01
Réseau

Créer un réseau interne VirtualBox LAB-IT en 192.168.50.0/24.

LOG 02
Serveur

Installer Windows Server 2025 puis AD DS, DNS et DHCP.

LOG 03
Domaine

Créer ad.lab-it.test et joindre le client Windows 11.

LOG 04
Organisation

Créer les OU et groupes Techniciens, Support, RH et Comptabilité.

LOG 05
Automatisation

Écrire des scripts PowerShell de diagnostic et de provisionnement depuis CSV.

05
OUTCOME結果Résultat

Outcome

Lab Active Directory

Le lab permet de travailler sur le domaine, les utilisateurs et groupes, le DNS, le DHCP et l’automatisation PowerShell avec un poste Windows 11 réellement joint à l’Active Directory.

06

L02Structurer OU et groupes avant d’automatiser le provisionnement.
L03Tester les scripts dans un environnement isolé et réinitialisable.
L04Identifier les différences utiles entre PowerShell 5.1 et PowerShell 7.

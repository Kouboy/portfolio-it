Project overview

Projet de formation combinant choix matériel et déploiement système : concevoir une workstation adaptée à AutoCAD 2027 dans une enveloppe donnée, puis préparer une chaîne MDT/WDS permettant d’installer Windows 11, les applications et les mises à jour de manière reproductible.
